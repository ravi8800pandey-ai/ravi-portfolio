## Local preview

Open `index.html` in a browser.

## website
https://ravi8800pandey-ai.github.io/ravi-portfolio/

## Publishing with GitHub Pages

This repository is a static website: no build command is needed. In GitHub, open **Settings → Pages**, select **Deploy from a branch**, then choose the `main` branch and the `/(root)` folder.
